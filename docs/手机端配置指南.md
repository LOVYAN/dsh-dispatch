# 手机端配置（Android）

最低配置：电脑 DeepSeek Harness 已装本插件并重启；手机与电脑登录**同一个** Tailscale 账号。

## 1. Tailscale

1. PC、手机都装 [Tailscale](https://tailscale.com/download)，同一账号。
2. PC 开 HTTPS 反代（`install.ps1` 会尝试执行；失败则手动）：

   ```powershell
   tailscale serve --bg --https=443 http://127.0.0.1:3080
   ```

3. 手机 Tailscale：电池无限制 + 允许自启动。掉线后 `*.ts.net` 打不开。
4. `publicBaseUrl` 就是 `tailscale status` 里本机的 `https://<机器>.<tailnet>.ts.net`，写在 `.dsh-home/profiles/web/cordis.patch.yml`。

## 2. 会话页（必做，不需要 ntfy）

浏览器打开安装脚本打印的地址：

```
https://<你的机器>.ts.net/dispatch/chat?token=<token>
```

- 列表可新开会话、点进已有会话看回复、底部续聊。
- 需要提权时，会话页**顶上**出现橙色横幅【✅ 批准】【❌ 拒绝】。
- 列表里对应会话会标「待审批」。
- token 在 URL 里，当口令保管；不要发到公开地方。

这就是「不用 ntfy 怎么批」：开着这个网页就能批。

## 3. 锁屏推送（可选，ntfy）

只在你希望锁屏震动时才装。

1. 安装 [ntfy](https://ntfy.sh)（Play / F-Droid）。
2. 订阅 `install.ps1` 打印的主题；服务器保持 `https://ntfy.sh`。
3. 长按订阅 → 打开 **即时传递 / Instant delivery**。
4. 系统设置 → ntfy → 通知（含锁屏）全开；电池无限制 + 自启动。

通知标题为「🔐 审批请求 · &lt;工具&gt;」，展开后有【✅ 批准】【❌ 拒绝】。国产 ROM 锁屏常把内容折叠成「有一条通知」，需要**下拉展开**才看得到按钮。

PC 发布走 `http://ntfy.sh`（80 端口）。插件已处理中间盒：非 ASCII 转 `\uXXXX`，`priority` 用数字。

公共主题靠随机名保密。换主题：改 `cordis.patch.yml` 的 `ntfyTopic` 并重启，手机重新订阅。

## 4. 快捷派单

也可用 HTTP Shortcuts / Tasker `POST /dispatch/task`，见 [手机派单-快捷指令配方.md](手机派单-快捷指令配方.md)。日常用会话页即可。

## 5. 探针

| 探针 | 地址 |
|---|---|
| 插件存活 | `GET http://127.0.0.1:3080/dispatch/health` |
| 待审 + 最近事件 | `GET /dispatch/status?token=…` |
| 会话页 | `GET /dispatch/chat?token=…` |

token 只存在本机 `cordis.patch.yml`，不要提交。
