# 手机派单快捷指令（可选）

日常建议直接用会话页。若要把「分享菜单里的一段字」打到 PC 上的 Agent，再用 HTTP Shortcuts / Tasker。

前提：Tailscale 已连接；插件已运行。`<base>` 为 `https://<机器>.ts.net`，`<token>` 见本机 `cordis.patch.yml`。

## HTTP Shortcuts

1. 安装 HTTP Shortcuts。
2. 新建 shortcut：
   - 方法：`POST`
   - URL：`https://<base>/dispatch/task`
   - Header：`Authorization: Bearer <token>`
   - Body：`application/json`

     ```json
     { "text": "{{任务内容}}" }
     ```

     `{{任务内容}}` 设为每次询问的文本变量。需要指定目录时加 `"cwd": "D:\\path\\to\\proj"`。
3. 成功响应：`{"ok":true,"sessionId":"session-..."}`。

## Tasker / MacroDroid

分享文本 / 手动触发 → HTTP Request，字段同上。

## 变体

| 需求 | body |
|---|---|
| 续接会话 | `"sessionId": "session-xxxx"` |
| 指定目录 | `"cwd": "D:\\path\\to\\proj"` |
| 指定预设 | `"agentPreset": "standard"` |
| 插话 | `"mode": "steer"` |

经 `/dispatch/task` 派出的会话跑完会推「✅ 任务完成」（若启用了 ntfy）。
