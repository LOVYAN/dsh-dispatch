# 设计摘要

产品目标：手机给本机 DeepSeek Harness **派任务、看回复、续聊、批权限**。  
不是复刻 GUI 聊天页。

## 决策

| 项 | 选择 |
|---|---|
| 平台 | Android（会话页任意能开浏览器的系统也能用） |
| 组网 | Tailscale；3080 只听回环 |
| 推送 | 可选。默认 ntfy.sh（PC 走 `http://ntfy.sh`）。不装 ntfy 也能在会话页批 |
| 插件形态 | Cordis `Service`，`inject = ['webServer','apiProxy']` |
| 审批通道 | 进程内 `InProcessApiClient` 订 mux，不抢 GUI 的 waterfall |

## 架构

```
手机浏览器  --Tailscale HTTPS-->  /dispatch/chat     看回复 / 续聊 / 页内批准
ntfy App    --ntfy.sh---------->  插件 POST 推送      锁屏按钮（可选）
插件         --进程内----------->  ctx.apiProxy        sessions.* / respond()
```

`/dispatch/*` 不在 `/api` 信任栅栏内，token 即鉴权。

## 审批

- 不在 `approval/request` waterfall 上插队（GUI 会先吃掉）。
- 用 mux 帧 `approval/requested` 的稳定 `rpcId` 调 `respond()`。
- 先答先赢；迟到 → 页上显示「该审批已被处理」。
- 去重键：`sessionId/approvalId`（不要赌 rpcId 跨重放稳定）。

## ntfy.sh 坑（HTTP/80）

1. 非 ASCII 会被中间盒损坏 → JSON `\uXXXX`。
2. `"priority":"high"` 会被拒 → 用数字 `4` 或 `5`。
3. 锁屏常折叠通知，要下拉才看到动作按钮。
4. 国产 ROM 会杀 Tailscale / ntfy 后台：电池无限制 + 即时传递。

## 实现入口

- 插件：`plugin/lib/index.js`
- 安装：`install.ps1`
- 路由：`/dispatch/health|status|decision|task|chat`

更细的历史踩坑不必进公开仓库；本文件只保留对后来贡献者有用的不变量。
